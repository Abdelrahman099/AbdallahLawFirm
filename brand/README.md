# هوية عبد الله الشهري

الشعار v3 معتمد، ومطبّق على النظام اللوني والتطبيقات المرفقة. دليل الهوية يشرح الفكرة، الألوان، الخط، مساحة الحماية، اختيار النسخ، المطبوعات، المحتوى، الموقع والحركة.

logos: 20 SVG و20 PNG شفافًا. أربعة تكوينات: أفقي كامل، أفقي مختصر، رأسي، ورمز مستقل. خمسة معالجات: أخضر وبرونزي، عاجي وبرونزي، أسود، أبيض، وأخضر أحادي. حروف SVG مسارات؛ لا تحتاج تثبيت الخط لعرضها.

fonts: IBM Plex Sans Arabic بثلاثة أوزان وترخيصه. applications: 15 تصورًا بصريًا للمطبوعات والمراسلات والمحتوى والموقع. index.html معرض لاختيار النسخة المناسبة للخلفية والتكوين. brand-book.html مصدر الدليل.

الأخضر #143E31، الأخضر العميق #0B241B، العاجي #F7F3EB، والبرونزي #B48753. البرونزي للتفاصيل؛ نصوص البرونزي على العاجي تستخدم #886239. لا تغيّر نسب الشعار أو تضف ظلالًا إلى الملفات الأصلية. معالجة المجسّم في الموقع تطبيق رقمي مستقل.

الشعار معتمد؛ العبارات والمحتوى والمعلومات التشغيلية وصور المكتب تحتاج مراجعة الجهة. الصور المعمارية في الموقع تصورية. المطبوعة تحتاج ملف إنتاج بالمقاس والنزف واللون قبل الطباعة.
