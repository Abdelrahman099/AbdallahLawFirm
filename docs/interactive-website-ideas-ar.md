# عشرة اتجاهات لتطوير تجربة المكتب

الاختيارات مبنية على الهوية المعتمدة: أخضر غامق، عاجي، وبرونزي للتفاصيل. الهدف أن تساعد الحركة الزائر على فهم الخدمة والوصول إلى الحجز. الصور الحالية تصورية وتُستبدل بصور المكتب عند توفرها.

| الفكرة | الشكل والتفاعل | الحالة والأولوية |
|---|---|---|
| ١. Slider الخدمات | ثلاثة مشاهد بصور مستقلة، كشف للصورة بـGSAP، انتقال للنص بـMotion، أسهم ولمس واختيار الخدمة. تشغيل تلقائي اختياري، يتوقف عند التركيز أو مرور المؤشر. | منفّذ في الرئيسية؛ الاتجاه المقترح الحالي |
| ٢. مجسّم الاتزان مع التمرير | ميزان ثلاثي الأبعاد من البرونز يستجيب للمؤشر، ويدور مع التمرير عبر GSAP ScrollTrigger. حركة المؤشر والتمرير على مجموعتين مختلفتين لمنع التعارض. | منفّذ للمقارنة في الاتجاه ١؛ يمكن استخدامه لاحقًا كفصل بصري داخل الرئيسية |
| ٣. ثلاثة توزيعات للهيدر | شريط أخضر وهيدر عاجي، أو أخضر كامل بشعار عكسي، أو عاجي مختصر. ارتفاع يتغير عند التمرير ومؤشر تنقّل متحرك. | منفّذ؛ ترشيحي الشريط الأخضر والهيدر العاجي |
| ٤. خمس افتتاحيات للبراند | رسم واتزان؛ نقاط تتجمع بعد حركة دائرية؛ فتح ملف بمنظور؛ ختم مع موجات؛ كشف طباعي بستائر. | منفّذ؛ ترشيحي رسم الاتزان، مرة في الجلسة مع تخطّي |
| ٥. رحلة القضية التفاعلية | مراحل فهم المسألة، تحديد الخيارات، الاتفاق والمتابعة. يظهر كل فصل مع شريط تقدم ووثائقه المطلوبة أثناء التمرير. | مقترح تالٍ، أولوية عالية؛ أساس المحتوى موجود في صفحة كيف نعمل |
| ٦. مستكشف الاحتياج القانوني | سؤالان قصيران يقترحان صفحة خدمة وتجهيزات الاستشارة المناسبة، مع إمكانية تغيير الإجابات. | مقترح، أولوية عالية؛ ليس تشخيصًا قانونيًا أو حكمًا على القضية |
| ٧. معاينة الوثائق المطلوبة | Checklist بحسب الخدمة، تتحرك عناصرها عند الاختيار، ويمكن حفظ القائمة للطباعة قبل الموعد. | مقترح، أولوية عالية؛ لا رفع ملفات حساسة في هذه المرحلة |
| ٨. انتقالات دليل الخدمات | إعادة ترتيب ناعمة لنتائج البحث والتصفية، وعدّاد نتائج واضح، وتوسّع اختياري لشرح الخدمة. | البحث والتصفية منفّذان؛ حركة إعادة الترتيب مقترحة |
| ٩. تجربة قراءة الإرشادات | شريط تقدم قراءة، فهرس فقرة نشطة، وتذكير بالحجز عند انتهاء الموضوع. | مقترح، أولوية متوسطة |
| ١٠. بطاقة زيارة المكتب | عرض المكان والمواعيد وطرق التواصل، مع توسّع للخريطة وتحديد استشارة عن بُعد أو بالمكتب. | مقترح بعد اعتماد بيانات المكتب وإحداثياته؛ العنوان موجود، الهاتف والمواعيد ناقصة |

## توزيع التقنيات

- **Three.js / React Three Fiber:** للمجسّمات والضوء والخامات. تحميل عند الحاجة، كثافة بكسلات محدودة، ورسم عند التفاعل بدل تشغيل مستمر؛ بديل ثابت عند عدم توفر WebGL.
- **GSAP:** لتتابعات الكشف وحركة المجسّم المرتبطة بالتمرير. استخدام `useGSAP` و`revertOnUpdate` لتنظيف التتابعات عند تغيير الشريحة أو مغادرة الصفحة.
- **Motion for React (Framer Motion):** لانتقالات المحتوى والمؤشر النشط والقوائم وحالات الحجز. لا تحرك الخاصية نفسها التي يتحكم فيها GSAP على العنصر نفسه.
- تفضيل الحركة المخففة يعطّل الحركة غير الأساسية والافتتاحية. المحتوى والروابط يعملان مستقلين عنها.
